# Тексты для карточки в Chrome Web Store

## Название
Weblate ⇄ Smartcat

## Краткое описание (до 132 символов, берётся из manifest.json)
Выгрузка непереведённого из Weblate, машперевод и файлы в Smartcat, загрузка переводов обратно с проверкой — в пару кликов.

## Подробное описание
Помощник для команды локализации, которая работает в Weblate и Smartcat. Открывается окном поверх Weblate по нажатию на значок.

Главная — всё в одном экране
• Вставь ссылки на компоненты, категории или весь проект Weblate, выбери языки (веб, мобильные или свои) и нажми «Выгрузить и отправить».
• Архивы для подрядчиков сохраняются сами, непереведённое уходит в Smartcat на машинный перевод.
• Шаги показывают, что сделано и что дальше. После отправки появляются готовые сообщения для рабочего чата: впиши дедлайн и скопируй.
• Сетапы для разных проектов и команд: свои ссылки, языки и проекты Smartcat.

Smartcat
• «Перевод готов → в Weblate»: отправки сгруппированы по датам, фильтр «2 дня / неделя / все». Когда перевод готов, приходит уведомление Chrome.
• «Загрузить файлы в Smartcat»: любые файлы в любой проект и папку, можно сразу создать новый проект или папку и выбрать языки.
• Все файлы из проектов Smartcat можно забрать обратно в Weblate, даже если их загружали вручную.

Загрузка обратно с проверкой
• Перетащи .po, .json или .zip от подрядчика — компонент и язык определятся сами.
• Расширение проверяет переменные и «мусор» от машинного перевода (пояснения и рассуждения ИИ). Если в мусоре есть сам перевод, он вытаскивается и загружается «На правку».
• После загрузки — список «Проверь в Weblate» со ссылкой прямо на каждую строку и отчёт с кнопкой «Скопировать».

Светлая и тёмная тема. Расширение работает от твоего входа в Weblate (токен не нужен). Ключ API Smartcat хранится только в расширении на твоём компьютере.

# Вкладка «Конфиденциальность» (Privacy practices)

## Единое назначение (Single purpose)
Выгрузка непереведённых строк из Weblate, их перевод через Smartcat и загрузка готовых переводов обратно в Weblate.

## Обоснование разрешений

**activeTab** — окно расширения открывается на текущей вкладке Weblate по нажатию на значок.

**scripting** — по нажатию на значок расширение добавляет своё окно на страницу Weblate. По клику на уведомление «перевод готов» и при отправке по расписанию оно открывает это окно на вкладке Weblate.

**storage** — хранит настройки на этом компьютере: адрес Smartcat, Account ID, API-ключ, сетапы проектов, наборы ссылок и список отправок в Smartcat.

**alarms** — раз в 2 минуты проверяет, закончил ли Smartcat перевод отправленных файлов (только отправки за последние 3 дня), и запускает отправку по расписанию, если пользователь её включил.

**notifications** — показывает уведомление «Smartcat: перевод готов», чтобы пользователь загрузил переводы в Weblate.

**Доступ к сайту Weblate** — запросы к API Weblate организации от имени вошедшего пользователя: скачать строки и загрузить переводы.

**Доступ к сайтам: smartcat.com и *.smartcat.com** — запросы к API Smartcat: отправка файлов на перевод, проверка готовности, скачивание переводов. Поддомены нужны для серверов us.smartcat.com и ea.smartcat.com.

## Удалённый код (Remote code)
Нет, удалённый код не используется. Весь JavaScript и шрифт находятся в пакете.

## Использование данных (Data usage)
Отметить:
- **Аутентификационная информация** — API-ключ Smartcat, который пользователь вводит сам. Хранится локально и отправляется только в Smartcat.
- **Контент веб-сайта** — строки для перевода из Weblate и файлы, которые пользователь сам выбирает для загрузки. Они отправляются в Smartcat только по действию пользователя.

Подтвердить все три пункта:
- данные не продаются третьим лицам;
- данные не используются и не передаются для целей, не связанных с единым назначением;
- данные не используются для определения кредитоспособности или кредитования.
