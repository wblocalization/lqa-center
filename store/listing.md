# Тексты для карточки в Chrome Web Store

## Название
Weblate: выгрузка и загрузка переводов

## Краткое описание (до 132 символов, берётся из manifest.json)
Выгрузка непереведённого из Weblate в .po, машинный перевод через Smartcat и загрузка переводов обратно — в пару кликов.

## Подробное описание
Помощник для команды локализации, которая работает в Weblate.

Выгрузка
• Вставь ссылки на компоненты, категории или весь проект, выбери языки и получи архив .po только с непереведёнными строками по каждому компоненту и языку.
• Раскладка по компонентам, по языкам или всё вместе. Плюралки (множественное число) — отдельным .json.
• Сохраняй часто используемые ссылки и языки как наборы.

Машинный перевод через Smartcat
• Одна кнопка: выгрузить непереведённое и отправить файлы в проект Smartcat (файл на каждый компонент и язык).
• Когда Smartcat закончит перевод, придёт уведомление Chrome.
• «Загрузить в Weblate» скачает переводы и загрузит их только в непереведённые строки.

Загрузка обратно
• Перетащи .po, .json или .zip от подрядчика — компонент и язык определятся сами по файлу.
• После загрузки — отчёт, сколько строк принято, с кнопкой «Скопировать».

Расширение работает от твоего входа в Weblate (токен не нужен). Ключ API Smartcat хранится только в расширении на твоём компьютере.

# Вкладка «Конфиденциальность» (Privacy practices)

## Единое назначение (Single purpose)
Выгрузка непереведённых строк из Weblate, их машинный перевод через Smartcat и загрузка готовых переводов обратно в Weblate.

## Обоснование разрешений

**activeTab** — окно расширения открывается на текущей вкладке Weblate по нажатию на значок.

**scripting** — по нажатию на значок расширение добавляет своё окно на страницу Weblate. Также по клику на уведомление «перевод готов» оно открывает это окно на вкладке Weblate.

**storage** — хранит настройки на этом компьютере: адрес Smartcat, Account ID, API-ключ, проекты, наборы ссылок. Там же хранится список отправок в Smartcat.

**alarms** — раз в 2 минуты проверяет, закончил ли Smartcat перевод отправленных файлов. Проверяются только отправки за последние 3 дня.

**notifications** — показывает уведомление «Smartcat: перевод готов», чтобы пользователь загрузил переводы в Weblate.

**Доступ к сайтам: weblate.wb.ru** — запросы к API Weblate от имени вошедшего пользователя: скачать строки и загрузить переводы.

**Доступ к сайтам: smartcat.com и *.smartcat.com** — запросы к API Smartcat: отправка файлов на перевод, проверка готовности, скачивание переводов. Поддомены нужны для серверов us.smartcat.com и ea.smartcat.com.

## Удалённый код (Remote code)
Нет, удалённый код не используется. Весь JavaScript находится в пакете.

## Использование данных (Data usage)
Отметить:
- **Аутентификационная информация** — API-ключ Smartcat, который пользователь вводит сам. Хранится локально и отправляется только в Smartcat.
- **Контент веб-сайта** — строки для перевода из Weblate. Они отправляются в Smartcat только по действию пользователя.

Подтвердить все три пункта:
- данные не продаются третьим лицам;
- данные не используются и не передаются для целей, не связанных с единым назначением;
- данные не используются для определения кредитоспособности или кредитования.
