# lqa-center

## Выгрузка непереведённых строк из Weblate

### Расширение для Chrome — значок на панели браузера

1. Скачай `weblate-extension.zip` из репозитория и распакуй (получится папка `weblate-extension`).
2. Открой в Chrome `chrome://extensions`, включи справа вверху **«Режим разработчика»**.
3. Нажми **«Загрузить распакованное расширение»** и выбери папку `weblate-extension`.
4. Закрепи значок (пазл 🧩 справа от адресной строки → булавка).
5. На weblate.wb.ru нажми значок — откроется окно: вкладки «⬇ Выгрузить» и «⬆ Загрузить обратно».
   На любом другом сайте значок просто откроет Weblate.

Папку `weblate-extension` не удаляй — Chrome берёт расширение из неё.
Обновление: распакуй новый архив (можно в ту же или другую папку) и нажми ↻ / «Загрузить
распакованное» — у расширения постоянный ID, поэтому настройки (Smartcat, проекты, языки,
ссылки) сохраняются. Для другого компьютера: ⚙ → «Сохранить настройки в файл» (без API-ключа).
Если на рабочем ноутбуке «Режим разработчика» заблокирован — используй закладку ниже, она делает то же самое,
или опубликуй расширение в Chrome Web Store: всё для этого лежит в [`store/`](store/README.md).

### Smartcat (только в расширении)

Вкладка «🤖 Smartcat» — сверху выбор сетапа и три блока:

**1. На машинный перевод.** Компоненты `global_site/wb-android` и `global_site/wb-ios_new` (меняются в «Компоненты и наборы»),
языки KK KY TG KA HY UZ EN + AZ (AZ только в ZIP; для android — `az_N11`, для ios — `az`).
«🚀 Выгрузить и отправить в Smartcat» — выгрузка + ZIP (папки `ДДММГГ_android/`, `ДДММГГ_ios/`) + отправка;
«Только скачать ZIP» — без отправки. Английский дополнительно кладётся **без папки** в проекты для английского
(android → `732af7d0…`, ios → `85c99769…`, меняются в ⚙) с именем `ДДММГГ_global_site-wb-android-en.po`; обратно оттуда не забирается.

**2. Перевод готов → в Weblate.** Список отправок из блока 1. Расширение раз в 2 минуты проверяет их (до 3 дней)
и показывает уведомление Chrome «Smartcat: перевод готов»; клик открывает эту вкладку. В строке отправки:
«⬆ В Weblate» (загрузка с «Изменять только непереведённые строки»), «⬇ ZIP», «×». Сверху «⬆ Загрузить всё готовое»,
а если отметить галочками — «⬆ Загрузить отмеченные» / «× Убрать отмеченные». «🔎 Найти отправки» восстанавливает список.
Загруженные отмечаются «✓ загружено в Weblate ДД.ММ ЧЧ:ММ».

**3. Готовые файлы из Smartcat → в Weblate.** Сразу видны все проекты аккаунта (свежие сверху, проект из сетапа — ⭐);
поиск по названию, а если вставить ссылку на проект — откроется он. Клик по проекту — его папки и файлы вне папок,
как в Smartcat; клик по папке — внутрь, путь сверху («Все проекты › МП Web › 280926 web») — назад.
Поиск внутри проекта ищет и папки, и файлы (имя, язык, дата). Галочка у папки отмечает все её файлы, у файла — только его;
статус «✓ готово» / «в работе N%», загружать можно и файлы в работе.
«⬆ Загрузить в Weblate» (только в непереведённые или заменять переведённые) или «Сначала посмотреть».
После «⬆ Загрузить в Weblate» результат показывается прямо в блоке 3 (на другую вкладку не перекидывает): сколько загружено,
что упало, что испортил Smartcat (со ссылками), какие плюралки вынесены в json, «Какие строки не легли», «По файлам», полный отчёт.
Загруженное помечается: у файла «✓ ДД.ММ», у папки «✓ в Weblate ДД.ММ ЧЧ:ММ» / «загружено X из N» / «новое»
(запоминается на этом компьютере); «скрыть уже загруженное» оставляет только то, что осталось.
Компонент и язык определяются по файлу, папке и языку документа в Smartcat (понимает и имена вида `b2b.en`, `kk(kk).po`, `aiAssistant.az(az-Latn).json`).
«⬇ Скачать ZIP» — отмеченное архивом с именами как в Weblate: `<компонент>/global_site-<компонент>-<язык>.po`, `<компонент>_<язык>_plural form.json`;
нераспознанное — в папку «не распознано».

**Отчёт о загрузке:** после каждой загрузки внизу — отчёт (компоненты, языки, сколько строк принято,
ошибки) и кнопка «📋 Скопировать отчёт», чтобы вставить в чат.

**Наборы:** на вкладках «⬇ Выгрузить» и «🤖 Smartcat» можно сохранить текущие ссылки
(и языки) как набор — «💾 Сохранить как набор» — и потом выбрать его из списка.
Наборы попадают и в файл настроек.

**Веб в Smartcat:** при отправке выгрузки (вкладка «⬇ Выгрузить» → «4. Отправить в Smartcat») для веба уходит **только английский** —
в проект «МП Web» (меняется в ⚙ → «Веб: английский → проект»), в папку «ДДММГГ web» (название можно поправить перед отправкой);
остальные языки веба остаются только в архиве. android и ios — как раньше.
Плюралки (.json) тоже уходят в Smartcat (для веба — только английские) и обратно загружаются в Weblate как .json.

**Папка для архивов:** ⚙ → «Папка для архивов» → «📁 Выбрать папку…» (например «Подрядчики» на рабочем столе).
Все zip (выгрузка непереведённого на вкладке «⬇ Выгрузить», «Только скачать ZIP», ZIP из Smartcat) сохраняются туда сразу,
по умолчанию в подпапку с датой `ДДММГГ`; одинаковые имена не затираются, а получают « (2)». Chrome может иногда
переспросить разрешение на папку. Если папка недоступна — архив скачается в «Загрузки» как обычно.

**Отправка android и ios по расписанию:** ⚙ → «Отправка android и ios по расписанию» → галочка «отправлять по расписанию»,
«Когда (по Москве)»: `вт 14:00, пт 10:00`. В это время расширение само открывает Weblate в фоновой вкладке и делает
«🚀 Выгрузить и отправить в Smartcat», итог приходит уведомлением Chrome. Нужно, чтобы компьютер и Chrome были включены
и ты была залогинена в Weblate. Пропущено (компьютер спал / Chrome закрыт) — уведомление с кнопкой «Отправить сейчас».
Если сегодня android / ios уже отправляли — второй раз не шлёт. «Запустить сейчас» — то же вручную. Включать на одном компьютере.

**Назначение на английский:** ⚙ → «Назначать на английский» → «Загрузить команду из Smartcat» → отметь людей.
После «Отправить в Smartcat» они сразу назначаются на английские документы (EN android, EN ios, веб в «МП Web»),
режим — все, кто принял. Документы машинного перевода (AI translation) не трогаются. Выбор хранится в расширении.

**Сетапы и настройки:** ⚙ открывает настройки отдельным экраном («← Назад» — вернуться). «Сетап» — свой проект Smartcat,
английские проекты и коды языков под задачу (например «Магазинка» и «Веб»); аккаунт и ключ общие.

Если Smartcat испортил строку в .po (обычно длинную, с эмодзи или неразрывным пробелом: кавычка не закрыта, конец исходника уехал в перевод —
Weblate отвечает «end-of-line within string» и не принимает весь файл), расширение само убирает только испорченные записи и загружает остальное;
их ключи видны в статусе файла и в отчёте («Испорчены в Smartcat — проверь вручную»).

Плюралки внутри .po для json-компонентов (i18next, например веб): Weblate их из .po не принимает («не найдено» —
у русского 3 формы, а в .po помещаются 2). Расширение само выносит их в отдельный `… — плюралки.json` и загружает;
если подрядчик прислал свой json с плюралками на тот же компонент и язык — берётся его json.

После загрузки, если что-то «пропущено» или «не найдено», ниже отчёта появляется **«Какие строки не легли»**:
ключ и русский текст каждой строки, причина (нет в компоненте / уже переведена / одобрена / только для чтения)
и ссылка прямо на строку в Weblate; список можно скопировать.

**Проверка переменных** (`{{count}}`, `%s`, `%1$d`, `{name}`, `$t(…)`, теги) в .po перед загрузкой:
✗ ошибка — переменная, которой нет в исходнике (`{{cuont}}`), или сломанная скобка (`{{count}`) — такие строки не загружаются
(галочка в «Как загружать»); ? проверь — переменная пропала, слиплась со словом, теги не совпадают.
С учётом языка: в az / tr / uz / ka / am окончания и приставки пишутся слитно (`{{count}}-dən`, `ለ{{count}}`) — не ошибка;
`%d`/`%s` ищутся только если они есть в исходнике (иначе «22%-dək» похоже на `%-d`); в плюралках форма «один» может быть без числа.

Если Weblate отвечает «Проверка перевода не включена» (режим «переведённые и одобренные» в компоненте без проверки, как в wb-web),
файл сам перезаливается с «Изменять переведённые строки».

Подробнее о шагах:

Схема «забрать строки → Smartcat (МП) → залить в Weblate только в непереведённые» в пару кликов:

1. Один раз: ⚙ в окне расширения → сервер Smartcat, **Account ID** и **API-ключ**
   (Smartcat → Настройки → API) → «Проверить подключение». Ключ хранится только в расширении
   на этом компьютере (в Weblate и в репозиторий не попадает).
2. Выгрузка как обычно; кнопка **«Набор для Smartcat: KK KY TG KA HY UZ EN»** отмечает нужные языки.
   Если в ⚙ указан **«Проект для машперевода»** (ссылка или название, например «AI translation 4 MP»),
   файлы добавляются в него в папки `ДДММГГ_android` / `ДДММГГ_ios` (путь в имени файла),
   новый проект не создаётся, а «Из Смартката» забирает только добавленные сейчас документы.
3. После выгрузки — шаг **«4. Отправить в Smartcat»** → «Отправить в Smartcat»:
   создаются проекты по платформе с датой отправки в начале — `290926_android`, `290926_ios`
   (компоненты без android/ios — `290926_web`; галочкой можно отправить всё одним проектом,
   названия можно поправить; если проект с таким именем уже есть — будет предупреждение).
   Отдельный файл на каждый компонент × язык со своими непереведёнными строками
   (`global_site-wb-android-hy.po` → только армянский), как при ручной загрузке;
   МП и претранслейт включены. Плюралки (.json) не отправляются.
4. Когда Smartcat закончит — вкладка «🤖 Smartcat» → «Отправленное в Smartcat» → «⬆ Загрузить в Weblate»:
   расширение скачает перевод каждого документа, разложит по компонентам и языкам и выставит
   **«Изменять только непереведённые строки»** → «Загрузить в Weblate».

Если Smartcat не принимает код языка — ⚙ → «Дополнительно» → «Коды языков» (например `uz_Latn=uz-Latn`);
там же можно добавить свои параметры создания проекта (JSON).

### Закладка — `index.html` (без программ и без токена)

1. Скачай `index.html` (или весь репозиторий: Code → Download ZIP) и открой его двойным кликом.
2. Перетащи зелёную кнопку **«⬇ Выгрузка Weblate»** на панель закладок браузера
   (панель включается `Ctrl+Shift+B`). Это делается один раз.
3. Открой weblate.wb.ru и нажми эту закладку — поверх Weblate откроется окно:
   ссылки → «Загрузить языки» → отметь языки → «Выгрузить» → скачай архивы.

4. Когда подрядчик вернёт файлы: та же закладка → вкладка «⬆ Загрузить обратно» →
   перетащи все .po/.zip сразу. Компонент и язык каждого файла определяются сами
   (по ссылке в заголовке `Language-Team`, иначе по имени файла и `Language`),
   дальше одна кнопка «Загрузить в Weblate». Режима «Заменить файл» нет специально —
   в файлах только часть строк.

При выгрузке можно выбрать, как разложить архив: **по компонентам**, **по языкам**
или **всё в одну папку**; английский по умолчанию всегда отдельно — в «Английский ШТАТ».
Файлы .po называются как при ручном скачивании из Weblate: `global_site-wb-ios_new-az_Latn.po`.
Плюралки (строки с множественным числом) по умолчанию выгружаются отдельным
`<компонент>_<язык>_plural form.json` в формате i18next (`ключ_one`, `ключ_other`… — набор форм
под каждый язык, значения — русский исходник для перевода), а в `.po` их нет.
При загрузке обратно `.json` принимаются так же, как `.po` (и имена из Smartcat: `b2b.kk(kk).json`, `kk(kk).po` — компонент берётся из папки; регистр и дефисы не важны: `aiAssistant` → `wb-web-ai-assistant`). Если компонент не нашёлся — его можно выбрать в колонке «Куда»; ключи, оставшиеся на русском,
не отправляются. Имена вида `b2b.ky.json` тоже понимаются (компонент ищется среди ссылок).

Ссылки можно вставлять не только на компоненты: ссылка на **категорию** (папка в Weblate,
как в seller-portal-dev) берёт все компоненты из неё, ссылка на **проект** — все компоненты
проекта (кроме глоссария). Компоненты из категорий называются в файлах
`<проект>-<категория>__<компонент>-<язык>.po`. Список найденных компонентов виден перед выгрузкой.

Языки показываются по-русски и с флагами (флаги — `bookmarklet/flags/<код>.svg`).

Закладка работает через твой обычный вход в Weblate, поэтому токен не нужен.
Код окна (общий для закладки и расширения) — `bookmarklet/weblate-export.js`;
после правок пересобрать: `python bookmarklet/build.py` (обновит `index.html`,
`extension/` и `weblate-extension.zip`).

### Способ с Python — страница с кнопкой через `Запустить.bat`

1. Один раз: установи Python с https://www.python.org/downloads/
   (при установке отметь галочку **Add python.exe to PATH**).
2. Скачай папку репозитория (Code → Download ZIP) и распакуй.
3. Дважды кликни **`Запустить.bat`** (на Mac — `Запустить.command`).
   Откроется страница в браузере. Чёрное окно не закрывай, пока работаешь.
4. На странице:
   - вставь API-токен (Weblate → Настройки → Доступ к API), он запомнится;
   - вставь ссылки на компоненты — можно прямо кусок сообщения из чата целиком;
   - нажми **Загрузить языки**, отметь нужные, нажми **Выгрузить**;
   - скачай архив на каждый язык (для подрядчика) или всё одним архивом.

В архиве `.po` по каждому компоненту, где есть непереведённые строки
(пустые + «требует правки»), в том же формате, что и «Скачать перевод → gettext PO».
Компоненты, где язык переведён на 100%, пропускаются.

> Нужен доступ к weblate.wb.ru (VPN, если обычно он нужен).

### Для командной строки — weblate_export.py

Скачивает `.po` с непереведёнными строками (пустые + «требует правки») сразу
для всех компонентов и всех языков, раскладывает по папкам и собирает zip на
каждый язык — можно сразу отправлять подрядчику.

Нужен только Python 3.8+ (ничего доустанавливать не надо).

### 1. Токен

Weblate → аватарка → **Настройки → Доступ к API** → скопировать токен.
Скрипт сам спросит его при запуске (или задай переменную `WEBLATE_TOKEN`).

### 2. Ссылки

Вставь ссылки на компоненты из запроса в `links.txt` — прямо как есть,
по одной в строке.

### 3. Запуск

```
python weblate_export.py --links links.txt --langs en ka kk uz ky hy tg am
```

Если непонятно, какие коды у языков в Weblate (например, `uz` или `uz_Latn`):

```
python weblate_export.py --links links.txt --list-languages
```

Короткий код (`uz`) скрипт сам сопоставит с `uz_Latn`, если вариант один.

### Результат

```
export_2026-09-28/
  Английский ШТАТ/wb-web-orders_en.po   ← английский всегда отдельно
  wb-web-orders/wb-web-orders_ka.po     ← остальные языки по компонентам
  wb-web-orders/wb-web-orders_kk.po
  ...
  en.zip            ← все файлы языка, для подрядчика
  ka.zip
  summary.csv       ← компонент / язык / строк / слов (открывается в Excel)
  errors.csv        ← если чего-то не нашлось
```

Компоненты, где язык уже переведён на 100%, пропускаются — пустых файлов не будет.
Имя `.po` = slug компонента, поэтому переводы потом легко загрузить обратно
в нужный компонент.

### Полезные опции

| Опция | Что делает |
|---|---|
| `--all-components --project global_site` | взять все компоненты проекта, без списка ссылок |
| `--components wb-web-orders wb-web-kids` | компоненты прямо в команде |
| `--query "state:empty"` | только пустые, без «требует правки» (синтаксис поиска Weblate) |
| `--out папка` | куда сохранить |
| `--no-zip` | не собирать zip |
| `--url https://...` | другой адрес Weblate |
