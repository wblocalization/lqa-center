# lqa-center

## weblate_export.py — выгрузка непереведённых строк из Weblate

Скачивает `.po` с непереведёнными строками (пустые + «требует правки») сразу
для всех компонентов и всех языков, раскладывает по папкам и собирает zip на
каждый язык — можно сразу отправлять подрядчику.

Нужен только Python 3.8+ (ничего доустанавливать не надо).

### 1. Токен

Weblate → аватарка → **Настройки → Доступ к API** → скопировать токен.
Скрипт сам спросит его при запуске (или задай переменную `WEBLATE_TOKEN`).

### 2. Ссылки

Вставь ссылки на компоненты из запроса в `links.txt` — прямо как есть,
по одной в строке.

### 3. Запуск

```
python weblate_export.py --links links.txt --langs en ka kk uz ky hy tg am
```

Если непонятно, какие коды у языков в Weblate (например, `uz` или `uz_Latn`):

```
python weblate_export.py --links links.txt --list-languages
```

Короткий код (`uz`) скрипт сам сопоставит с `uz_Latn`, если вариант один.

### Результат

```
export_2026-09-28/
  en/wb-web-orders.po
  en/wb-web-kids.po
  ...
  en.zip            ← все файлы языка, для подрядчика
  ka.zip
  summary.csv       ← компонент / язык / строк / слов (открывается в Excel)
  errors.csv        ← если чего-то не нашлось
```

Компоненты, где язык уже переведён на 100%, пропускаются — пустых файлов не будет.
Имя `.po` = slug компонента, поэтому переводы потом легко загрузить обратно
в нужный компонент.

### Полезные опции

| Опция | Что делает |
|---|---|
| `--all-components --project global_site` | взять все компоненты проекта, без списка ссылок |
| `--components wb-web-orders wb-web-kids` | компоненты прямо в команде |
| `--query "state:empty"` | только пустые, без «требует правки» (синтаксис поиска Weblate) |
| `--out папка` | куда сохранить |
| `--no-zip` | не собирать zip |
| `--url https://...` | другой адрес Weblate |
