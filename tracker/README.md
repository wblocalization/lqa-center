# Таблица задач переводчиков

Общая Google Таблица, куда расширение «Weblate: выгрузка и загрузка» само записывает задачи:

- **после выгрузки** — шаг «4. Записать задачу в таблицу»: задача, ссылка, команда, срок, языки,
  строки/слова, переводчик и редактор по каждому языку, Smartcat, кто выгрузил;
- **после загрузки переводов обратно** — строки сами получают статус «Загружено»
  (или «Частично (1/3)», если загружены не все компоненты задачи), дату и кто загрузил.

Одна строка = задача × язык. Если выгрузить ту же задачу ещё раз, строка обновится, а не задвоится.

## Настройка (один раз, ~5 минут, делает один человек)

1. Создай новую Google Таблицу, например «Задачи переводчиков».
2. В таблице: **Расширения → Apps Script**.
3. Удали всё в открывшемся файле `Code.gs` и вставь содержимое [`Code.gs`](Code.gs) из этой папки.
4. В строке `var TOKEN = 'ПОМЕНЯЙ-МЕНЯ';` впиши своё слово-пароль (латиницей, без пробелов),
   например `var TOKEN = 'loc-tracker-7f3k';`. Сохрани (💾).
5. Вверху выбери функцию **setup** и нажми **▶ Выполнить**. Google попросит доступ к таблице —
   разреши (если пишет «приложение не проверено»: «Дополнительно» → «Перейти…»).
   В таблице появятся листы **«Задачи»** и **«Переводчики»**.
6. **Начать развёртывание → Новое развёртывание** → тип (⚙) **Веб-приложение**:
   - «Запуск от имени»: **Я**;
   - «У кого есть доступ»: **Все** (иначе расширение не достучится; от чужих защищает токен).
   Нажми «Начать развёртывание» и скопируй **URL веб-приложения** (`https://script.google.com/macros/s/…/exec`).
7. Лист **«Переводчики»** уже заполнен при `setup` — из дашборда локализации:
   8 штатных переводчиков/редакторов EN (Валерия Гасанова, Виктория Гусева, Влада Тимощенко,
   Дмитрий Меделяновский, Максим Селищев, Мария Трофимова, София Горская, Татьяна Козлова)
   и подрядчики (LogrusIT, LogrusGlobal, Бюро переводов, JanusWW, Awatera).
   Колонки: **Язык** (код `en`, `ky`…, название «армянский» или `*` — любой язык) ·
   **Имя** · **Роль** («переводчик», «редактор», «переводчик, редактор» или «подрядчик»).
   Дописывай людей в конец. Переводчики попадают в подсказки колонки «Переводчик»,
   редакторы — «Редактор», подрядчики — только в «Переводчик». Если на язык один свой
   переводчик (не подрядчик) — расширение подставит его само.

## Подключение у каждого в команде

В окне расширения нажми **⚙** вверху → вставь **ссылку** из шага 6 и **токен** из шага 4,
впиши своё имя → «Проверить подключение» → должно быть «✓ Подключено».

Чтобы не раздавать ссылку каждому: положи её в `bookmarklet/tracker.config.json`
(`{"url": "https://script.google.com/macros/s/…/exec", "token": "…"}`) и пересобери
`python bookmarklet/build.py` — расширение и закладка будут подключены сразу.
Этот файл в git не хранится.

## Если поменяла `Code.gs`

Apps Script → **Начать развёртывание → Управление развёртываниями** → ✏ → версия «Новая» →
«Развернуть». Ссылка остаётся прежней.

## Важно

- Записи в таблицу работают в **расширении**. Закладка из `index.html` тоже попробует,
  но защита Weblate может её не пустить — тогда будет сообщение об этом.
- В таблицу попадают номер задачи, компоненты, языки, объёмы и имена — проверь, что это
  можно хранить в Google Таблицах по вашим правилам.
